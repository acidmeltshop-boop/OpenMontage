# Reference posters — Shinjuku Protocol

Art-direction source for the `shinjuku-protocol-reveal` production
(10s neo-noir character-reveal trailer, animation pipeline, HyperFrames runtime).

Drop the three poster PNGs here:

| File | Poster |
|---|---|
| `poster_01_illustrated.png` | Crimson silhouette, beer glass, cast + crew list, `2023.04.29` |
| `poster_02_photographic.png` | `DARK YAKUZA` / `FILM C-41` / `COORDINATES 35°41'N 139°46'E` |
| `poster_03_editorial.png` | Wide `SHINJUKU // PROTOCOL`, grid panels, barcode, colour bars |

These are the only source of subject-matter artwork for the production — no image
or video generation provider is configured on the build machine, so every plate in
the trailer is derived from these files.
