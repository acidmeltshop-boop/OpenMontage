# THE STOP — asset specification

60s, 16:9, 1920×1080, 30fps. Subject: modern manifestation.

Everything here is generated by the human operator and dropped into
`compositions/the-stop/assets/` using the **exact filenames** below. Filenames are
load-bearing — the composition wires assets by name.

---

## 0. Read first

**Aspect ratio — confirm before generating.** Everything below assumes **16:9
landscape**, because the supplied hero image is 16:9 and it's the lens for the piece.
If this is destined for Reels/TikTok/Shorts, say so *before* generating — every frame
below has to be recomposed for 9:16, and regenerating after the fact is wasted work.

**Style consistency is the whole ballgame.** Nine images generated independently will
drift into nine different shows. Two rules prevent that:

1. **Attach `img-01-hero.png` as a reference image on every single generation.** The
   text prompts below assume it is attached. Prompt text alone will not hold the
   character.
2. **Generate video by image-to-video, never text-to-video.** Make the still first,
   approve it, then feed *that still* to Omni / MiniMax with only a motion prompt.
   Text-to-video will invent its own style and break the cut.

**Cutouts use a magenta key, not transparency.** Where a subject must be isolated, the
prompt asks for a flat `#FF00FF` magenta background. Magenta appears nowhere in a
grayscale illustration, so it keys out perfectly with ffmpeg. Do **not** substitute
white — the character's shirt and socks are near-white and would key with holes.

**Design system pending.** Phoenix Dialectic was not readable from this session
(`claude.ai/design/p/...` is not fetchable here). The piece is built monochrome from
the hero image. An accent color has exactly one job in this edit — the turn at S10 —
so dropping Phoenix Dialectic in later is a one-token change, not a rebuild.

## 1. STYLE ANCHOR — prepend verbatim to every image prompt

```
Monochrome grayscale illustration, no color anywhere. Clean bold black ink linework
of confident uniform weight, digital manga / webtoon aesthetic. Flat tonal fills in a
limited grayscale range — white, light gray, mid gray, charcoal, black. No gradients,
no cross-hatching, no rendering noise. Subtle paper grain over the whole image. Hard
edged cast shadows with clean straight diagonal edges. Restrained, melancholy,
contemporary urban mood. No text, no lettering, no watermark, no signature.
```

## 2. CHARACTER ANCHOR — append to every shot containing the protagonist

```
The same young man throughout: early-to-mid twenties, messy short black hair with an
uneven spiky fringe, light stubble across chin and jaw, heavy-lidded tired eyes with
visible shadow beneath them, thin eyebrows, plain light-gray short-sleeve t-shirt with
a small chest pocket, black slim-fit jeans, black slip-on canvas sneakers with white
soles, white socks.
```

## 5. Built in code — do NOT generate these

To keep the generation list short, these are authored in HTML/CSS/GSAP, not supplied:

| Element | Why in code |
|---|---|
| All typography, including the giant kinetic type | Needs frame-accurate sync to narration |
| Hand-drawn arrows | SVG paths with hand-wobble; must animate as draw-on |
| UI card chrome, stacking cards | Real UI animates better than a picture of UI |
| Progress bar stuck at 97%, loading spinner | Must be timed, not static |
| Camera shake, rapid zooms, parallax | Transform math on supplied layers |
| Text masked behind subject | Compositing `img-03` over the type layer |
| Grain, vignette, border frame | Matches the hero image's own border treatment |
