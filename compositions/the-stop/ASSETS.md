# THE STOP — asset specification

60s · **9:16 vertical · 1080×1920** · 30fps. Subject: modern manifestation.

Everything here is generated by the human operator and dropped into
`compositions/the-stop/assets/` using the **exact filenames** below. Filenames are
load-bearing — the composition wires assets by name.

---

## 0. Read first

**The supplied hero image is now a reference, not a plate.** `img-01-hero.png` (the
16:9 bus-shelter illustration) can't be the on-screen background in a vertical film —
cropping it to 9:16 would throw away the shelter and the street that make the shot
read. So it has a new job: it is the **style and character reference attached to every
generation**, and the hero shot itself gets recomposed vertically as `img-02`.

**Attach `img-01-hero.png` as a reference image on every single generation.** Every
prompt below is written assuming it is attached. Text alone will not hold the
character across ten images.

**Video is image-to-video only.** Generate the still, approve it, then feed *that
still* to Omni / MiniMax with only a motion prompt. Text-to-video will invent its own
style per clip and break continuity at every cut.

**Cutouts use a green key.** Where a subject must be isolated, the prompt asks for a
flat `#00FF00` background. Green appears nowhere in a grayscale illustration and
nowhere in the Phoenix palette, so it keys out cleanly and is unambiguous. Do **not**
substitute white — his shirt and socks are near-white and would key with holes. This
was magenta in an earlier revision; it changed because magenta is now a brand color,
and asking a model for "magenta" risks getting Phoenix magenta instead of key magenta.

**Vertical framing is a rethink, not a crop.** Each prompt below states its vertical
composition explicitly — what sits at the top of the frame, what sits at the bottom.
Follow that language; it's what makes the cuts work.

**Phoenix Dialectic is now in hand** (supplied as an HTML export, rendered and read).
It changes the *composition* layer — ground, type, color logic — but **not one word of
the prompts below**. The assets stay monochrome ink on paper; Phoenix is applied in
code around them. Generate against this spec as written.

## 1. STYLE ANCHOR — prepend verbatim to every image prompt

```
Monochrome grayscale illustration, no color anywhere. Clean bold black ink linework
of confident uniform weight, digital manga / webtoon aesthetic. Flat tonal fills in a
limited grayscale range — white, light gray, mid gray, charcoal, black. No gradients,
no cross-hatching, no rendering noise. Subtle paper grain over the whole image. Hard
edged cast shadows with clean straight diagonal edges. Restrained, melancholy,
contemporary urban mood. Vertical 9:16 composition. No text, no lettering, no
watermark, no signature.
```

## 2. CHARACTER ANCHOR — append to every shot containing the protagonist

```
The same young man throughout: early-to-mid twenties, messy short black hair with an
uneven spiky fringe, light stubble across chin and jaw, heavy-lidded tired eyes with
visible shadow beneath them, thin eyebrows, plain light-gray short-sleeve t-shirt with
a small chest pocket, black slim-fit jeans, black slip-on canvas sneakers with white
soles, white socks.
```

## 5. Built in code — do NOT generate these

| Element | Why in code |
|---|---|
| All typography, including the giant kinetic type | Needs frame-accurate sync to narration |
| Hand-drawn arrows | SVG paths with hand-wobble, animated as draw-on |
| UI card chrome and the stacking cards | Real UI animates better than a picture of UI |
| Progress bar pinned at 97%, loading spinner | Must be timed, not static |
| Camera shake, rapid zooms, parallax | Transform math applied to your layers |
| Text masked behind subject | Compositing `img-04` over the type layer |
| Grain, vignette, border frame | Matches the hero image's own border treatment |
