# stillwater

A creative experiment space inside OpenMontage.

Scope and contents are still being defined. This directory is tracked in git
(unlike `projects/`, which is gitignored because it holds regenerable run
output), so anything committed here is intended to be kept.

## Conventions

Production runs still follow the normal OpenMontage pipeline described in
[`AGENT_GUIDE.md`](../AGENT_GUIDE.md); generated assets and renders belong in
`projects/<name>/`, not here. Use this directory for the durable parts of the
experiment: notes, specs, custom compositions, and any code it grows.
